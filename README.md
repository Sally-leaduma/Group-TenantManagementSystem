# Tenant Management System

An Android application built with Kotlin and Jetpack Compose for managing rental properties, units, and tenant records locally using Room persistence.

## Features
- **Tenant Registration & Directory:** Add, view, and manage tenant details.
- **Local Persistence:** Offline-first data storage powered by Android Room Database.
- **Modern UI:** Built with Jetpack Compose and Material 3 components.

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM (ViewModel, StateFlow/LiveData)
- **Local Database:** Room Persistence Library
- **Navigation:** Jetpack Navigation Compose
