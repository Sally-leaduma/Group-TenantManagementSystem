# Tenant Management System

An Android application built with Kotlin and Jetpack Compose for managing rental properties and tenant records offline using Room Database.

## Features
- **Tenant Registration:** Add and store tenant details locally.
- **Tenant Directory:** View saved tenant records cleanly.
- **Offline Persistence:** Powered by Android Room Database so data persists across sessions.

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose & Material 3
- **Architecture:** MVVM (ViewModel & StateFlow)
- **Database:** Room Persistence Library
- **Navigation:** Jetpack Navigation Compose
